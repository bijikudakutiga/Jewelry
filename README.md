# Xancovia Jewelry (Demo)

Website statis (satu file `index.html`). Default night mode, bisa ganti ke day mode lewat tombol ☀/☾ di menu.
Login hanya dummy (tanpa database). Pembayaran Midtrans hanya simulasi.

## Deploy ke Cloudflare Pages
1. Push repo ini ke GitHub.
2. Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git → pilih repo.
3. Build command: kosongkan. Build output directory: `/` (root). Klik Save and Deploy.
